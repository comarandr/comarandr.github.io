## Fogli di stile

I cascading Style Sheets (CSS), o fogli di stile servono a formulare e gestire il layout di un sito web. Posso essere inseriti più volte in uno stesso documento seguendo regole gerarchiche precise. Servono essenzialmente a ridefinire e/o potenziare i tag HTML.

### Regole

```css
selector { property: value;}

h1 { color: white; background: red; }
```

Le regole sono composte da due parti:

- **selettore**: definisce parte del documento a cui applicare le regole
- **blocco delle dichiarazioni**: racchiuso tra parentesi graffe, contiene una o più dichiarazioni separate da punto e virgola. Ogni dichiarazione è composta da una **proprietà** e un **valore**

### Commento

per commentare il codice CSS si utilizza la sintassi `/* commento */`
